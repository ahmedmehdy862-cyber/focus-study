# Focus Study — نسخة 0.2

## QUBIXStore and release synchronization

The public app card and detail page are served by [QUBIXStore](https://qubixstore.vercel.app/focus-study-updates). QUBIXStore reads the current app description, version, release notes, and APK URL from `https://update-site-sigma.vercel.app/api/latest`; the Android app reads the same release record and opens the QUBIXStore page for update notices.

The update-site `/admin/` panel is the single manual publishing point. It can upload a signed APK directly to Vercel Blob or accept a public HTTPS `.apk` URL, then publishes metadata for both clients. For tag-based automation, `.github/workflows/focus-study-release.yml` builds a signed APK, creates a public GitHub Release, and posts new metadata to the same central feed. Use tags like `focus-v0.12.0` matching Gradle `versionName`, and always increase `versionCode`.

GitHub repository secrets used by the workflow: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`, and `FOCUS_RELEASE_SYNC_TOKEN`. The central Vercel project needs `BLOB_READ_WRITE_TOKEN`, `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET`, and `FOCUS_RELEASE_SYNC_TOKEN`. Keep the signing key consistent with the APK already distributed so Android can install upgrades over the current app and retain its data.

```powershell
git add .
git commit -m "Connect Focus Study releases to QUBIXStore"
git push origin main
```

For each future release, first update `versionCode` and `versionName`, commit those changes, then create and push the matching tag, for example `git tag focus-v0.12.0; git push origin focus-v0.12.0`. GitHub Actions publishes the APK and automatically refreshes the central feed; QUBIXStore and Focus Study read the new version without another store code edit.

تطبيق أندرويد أصلي يجمع **تنظيم المهام والوقت** مع **حجب التطبيقات فعليًا** أثناء جلسة التركيز، وليس مجرد قطع الإنترنت.

## ما يفعله الآن

1. **مهام**: تضيف مهمة باسمها ومدة مخططة (15–90 دقيقة)، ولكل مهمة قائمة تطبيقات مشتّتة خاصة بها.
2. **جلسة تركيز مرتبطة بمهمة**: من شاشة الإعداد تحدد المدة والتطبيقات وتمنح الأذونات، ثم تبدأ جلسة مقفلة بمؤقّت تنازلي.
3. **حجب على مستويين** أثناء الجلسة:
   - **منع الفتح**: خدمة وصول ترصد التطبيق الذي يُفتح، تُغطّيه بشاشة حجب كاملة وتُعيدك للرئيسية.
   - **قطع الشبكة**: نفق `VpnService` يضم التطبيقات المختارة وحدها ويُسقط حزمها، فبقية التطبيقات تبقى متصلة.
4. **تسجيل التقدّم**: عند انتهاء مدة الجلسة فقط تُضاف الدقائق إلى المهمة، وتُحدَّث نسبة الإنجاز تلقائيًا.
5. **استعادة الحالة**: الجلسة محفوظة في قاعدة البيانات، فإن أُعيد تشغيل التطبيق تُستأنف أو تُغلق بأمان إن انتهى وقتها.

## الأذونات المطلوبة ولماذا

| الإذن | الغرض | إن رفضته |
|---|---|---|
| خدمة الوصول (Accessibility) | إخفاء التطبيقات المختارة ومنع فتحها | لا تبدأ الجلسة (إذن إلزامي) |
| إذن VPN | قطع شبكة التطبيقات المختارة | لا تبدأ الجلسة (إذن إلزامي) |
| الإشعارات | إشعار الجلسة الدائم ومؤقّتها (بلا زر إيقاف) | لا تبدأ الجلسة على Android 13+ |
| تعطيل تحسين البطارية | منع النظام من إنهاء الجلسة في الخلفية | اختياري، لكنه مُستحسن |

خدمة الوصول **لا تقرأ محتوى الشاشة ولا النصوص ولا المدخلات** — فقط اسم الحزمة في المقدمة، ولا تُرسل أي بيانات خارج الجهاز.

## التثبيت

```bash
adb install -r artifacts/focus-study-poc-debug.apk
```

عند أول تشغيل تظهر شاشة إعداد الجلسة قائمة الأذونات؛ اسمح بالإشعارات، وفعّل خدمة *Focus Study* من **«فتح إعدادات الوصول»**، وامنح إذن VPN، ويُستحسن تعطيل تحسين البطارية. زر البدء يبقى معطّلًا حتى تكتمل الأذونات الإلزامية ويُحدَّد تطبيق واحد على الأقل.

## القيود المعروفة (مهمة)

- **لا يوجد ضمان مطلق**: يمكن للمستخدم تعطيل خدمة الوصول أو إذن VPN أو إيقاف التطبيق. الحجب الحقيقي غير القابل للتجاوز يحتاج **Device Owner** (`setPackagesSuspended`) أي تهيئة مؤسسية أو إعادة ضبط المصنع — خارج نطاق الاستخدام العادي.
- التطبيقات المحجوبة قد تظهر لثانية واحدة قبل تغطيتها، لأن الكشف يعتمد على حدث تغيّر النافذة.
- حجب تطبيقات النظام (الهاتف، الرسائل، الإعدادات) خطر — لا تُضفها.
- خدمة الوصول مستهلكة للبطارية بشكل طفيف أثناء الجلسة فقط.

## وضع Device Owner (اختياري)

المنع الافتراضي يعمل بلا أي صلاحيات مؤسسية (شاشة حجب + VPN). لتعطيل التطبيقات على مستوى النظام — تعطيل الأيقونة، إخفاؤها من قائمة التطبيقات الأخيرة، ومنع نشاطاتها وإشعاراتها وصوتها — فعّل التطبيق كـ Device Owner مرة واحدة:

```bash
adb shell dpm set-device-owner com.focusstudy.poc/.FocusDeviceAdminReceiver
```

- المتطلبات: جهاز بلا حسابات مسجّلة (غالبًا بعد إعادة ضبط المصنع) وتصحيح USB؛ الأمر يُنفّذ مرة واحدة من الكمبيوتر.
- عند بدء الجلسة تُستدعى `setPackagesSuspended` للحزم المختارة، وعند انتهاء المدة تُستدعى ثانيةً للإلغاء.
- الحزم التي يرفضها النظام (تطبيقات النظام، اللانشر، الحزم التي عليها admin) يتجاهلها التطبيق ويبقى عليها الحجب العادي.
- عند إعادة فتح التطبيق تُقرأ الجلسة من قاعدة البيانات: إن انتهت تُلغى كل التعليقات تلقائيًا (self-heal) حتى لو أُغلق التطبيق أثناء الجلسة.
- منبّه نهاية الجلسة (`AlarmManager`) يوقظ التطبيق في وقت الانتهاء لتحرير التطبيقات حتى لو كانت العملية مقتولة.
- اللانشر الافتراضي في Android يعرض التطبيق المعلّق رماديًا ويُظهر رسالة نظام عند النقر؛ فلا يُخفى الأيقونة كليًا بل تُعطّل، وهذا سلوك النظام.
- عند إعادة تشغيل الهاتف تنتهي الجلسة الحالية (لا يوجد استئناف تلقائي بعد الإقلاع بعد).

## الهوية البصرية

- **الشعار**: درع (الحجب/الانضباط) يحتوي صاعقة (الطاقة/الدراسة)، مرسوم كـ vector في `res/drawable/ic_launcher_foreground.xml` مع خلفية متدرّجة `ic_launcher_background.xml` (أزرق ← بنفسجي)، ويعمل كأيقونة تكيّفية على كل إصدارات Android المدعومة. نفس العلامة مرسومة برمجيًا في `Brand.kt` لتُستخدم داخل الواجهة بأي حجم دون فقدان حدة.
- **لوحة الألوان** (`Theme.kt`): خلفية كحلية عميقة `#070B16`، أزرق كهربائي `#3B82F6`، بنفسجي `#8B5CF6`، تركوازي `#14B8A6`، كهرماني `#F59E0B`، أخضر `#22C55E`، أحمر وردي `#F43F5E`.
- **عناصر حيّة**: خلفية متدرّجة مع هالتين تتحركان ببطء، حلقة مؤقّت مرسومة بتدرّج لوني، شريط تقدّم متحرك لكل مهمة، حلقة نسب في البطاقة الرئيسية، ونقطة نابضة أثناء الجلسة، وانتقالات ناعمة بين الشاشات.
- **الوضع**: داكن فقط حاليًا (خلفية الشاشة الأولى داكنة أيضًا لمنع الوميض الأبيض عند الإقلاع).
- **التباين**: كل النصوص الأساسية ≥ 10:1 على الخلفية الكحلية، والثانوية ≥ 10:1، وألوان التأكيد تُفتَّح تلقائيًا عند استخدامها كنص (`FocusColors.onTint`)، وأحجام الخطوط رُفعت (14–27sp).

## شاشة إعداد الجلسة

قبل بدء أي جلسة تظهر شاشة إعداد واحدة تجمع كل ما يُحدَّد مسبقًا:

1. **المدة**: أزرار سريعة (15/25/45/60/90) + شريط تمرير من 5 إلى 120 دقيقة.
2. **التطبيقات**: قائمة كل التطبيقات القابلة للفتح مع بحث وتحديد متعدد و«اختيار الكل/مسح»؛ الحفظ يُحدِّث التطبيقات الافتراضية للمهمة.
3. **الأذونات**: إذن الوصول (Accessibility) + إذن VPN + إذن الإشعارات (Android 13+) — إلزامية، وتعطيل تحسين البطارية — مُستحسن. زر البدء معطّل حتى تكتمل الأذونات الإلزامية ويُحدَّد تطبيق واحد على الأقل.
4. **تأكيد صريح**: حوار يوضّح المدة وعدد التطبيقات وأن الجلسة لا تُلغى قبل انتهاء الوقت.

## الجلسة المقفلة ومنع الفتح

- بعد البدء **لا يوجد أي زر لإلغاء الجلسة**؛ لا في التطبيق ولا في شاشة الحجب ولا في الإشعار. الجلسة تنتهي فقط عند وصول المؤقّت إلى الصفر (أو عند استعادة الجلسة بعد انتهائها)، وعندها فقط تُحرَّر التطبيقات وتُسجَّل الدقائق.
- منع الفتح: مراقبة التطبيق المقدَّم عبر AccessibilityService، ثم تغطيته بشاشة إخفاء **معتمة تمامًا** (`TYPE_ACCESSIBILITY_OVERLAY`)، إرسال المستخدم للرئيسية، وقتل العملية الخلفية (`killBackgroundProcesses`)، مع فحص متكرر كل 0.9 ثانية ما دام التطبيق المقفل في المقدمة.
- الشبكة: نفق VPN يسمح فقط بحزم التطبيقات المختارة ويسقطها؛ سحب إذن VPN لا يوقف الجلسة، بل يظهر تنبيه داخلها مع زر لإعادة تشغيل الحجب.
- سحب إذن الوصول أو إيقاف التطبيق قسرًا من إعدادات النظام يوقف المنع؛ لا يمكن منع ذلك بدون صلاحيات Device Owner/Enterprise.
- الإشعار الدائم يعرض المهمة وعدد التطبيقات المقفلة دون أي زر إيقاف.
